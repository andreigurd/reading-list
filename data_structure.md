# Reading List Data Structure

## Book Object
- title (string)
- author (string)  
- status (Want to Read / Reading / Finished)
- rating (int 1-5, only if Finished)
- review (string, optional)
- date_added (string)
- date_finished (string, only if Finished)
- current_page (int, only if Reading)
- total_pages (int)
