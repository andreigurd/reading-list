# Reading List Tracker

A simple command-line reading list tracking application. Track books you want to read, are reading, and have finished. Rate and review them!

## Features
1. Add a book
2. View all books
3. View by status (Want to Read / Reading / Finished)
4. Move book to different status
5. Add rating and review
6. Search by title or author
7. Delete a book
8. Save/load from JSON
9. auto Track and display reading pace
10. Track reading goal
11. Export reading stats report
12. Recommend random book from "Want to Read" list
13. Statistics Feature:
    - Total books tracked
    - Average rating of finished books
    - Books finished this month
    - Most read author
    - Current reading streak

## How to Run
```bash
python reading_list.py
